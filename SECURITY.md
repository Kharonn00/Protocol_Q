# Security Policy

## Supported Versions

We support the following versions of this software with security updates:

| Version | Supported |
| ------- | --------- |
| 0.1.0   | Yes       |
| < 0.1.0 | No        |

## How to Report a Vulnerability

Do not open a public GitHub issue for security vulnerabilities. Public issues expose the security risk before a fix is ready.

To report a vulnerability:
1. Send an email to: `work4a2@gmail.com`
2. Write a clear description of the vulnerability.
3. List the steps to reproduce the vulnerability.
4. Provide any proof-of-concept code that demonstrates the problem.

We will check your report. We will respond to your email within 48 hours to confirm we received it.

## Our Response Process

1. **Investigation**: We will investigate the issue. We will update you on our progress.
2. **Fix**: We will develop a fix for the vulnerability.
3. **Release**: We will release the fix in a new update.
4. **Disclosure**: We will publish a security advisory to inform the community. We will credit you for the discovery if you request it.
